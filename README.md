# Airline Booking System
A PHP + MySQL airline management project (BCA final year project).

## Setup
1. Install XAMPP and start Apache and MySQL
2. Copy this project folder into `htdocs/`
3. Import `airline_db.sql` in phpMyAdmin
4. Edit `db.php` if your MySQL password is not empty
5. Open http://localhost/your-folder-name/ in your browser
